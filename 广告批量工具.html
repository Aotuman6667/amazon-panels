批量创建：清单列说明

列说明
ASIN / SKUSC 卖家填 SKU（ASIN 可留空）；VC 供应商填 ASIN（SKU 留空也行，会忽略）
投放关键词多个用 逗号/分号 分隔，自动拆成多个关键词行；自动广告留空
匹配方式exact / phrase / broad，默认 exact
关键词竞价USD留空=继承广告组默认出价（默认 0.75）
投放类型manual（默认）/ auto（不填关键词，亚马逊自动建 4 个目标组）
活动名称留空自动命名 SP-{ASIN}-{日期}；同名多行合并成一个活动
广告组名称留空=ASIN；同活动+同组名共用广告组
每日预算USD默认 20
竞价策略Fixed bid / Dynamic bids - down only / Dynamic bids - up and down
顶部加价% / 商品页面加价% / 其余加价%只填数字：+20% 就填 20（填 0.2 = 0.2%）。0–900，留空=不加价
竞价下限USD / 竞价上限USD出价保护，把出价夹在区间内
自动-紧密匹配 / 自动-宽泛匹配 / 自动-同类商品 / 自动-关联商品 仅自动广告有效，下拉选 启用 / 暂停 / 不建（留空）。对应亚马逊自动广告的 4 个目标组： close-match（紧密）/ loose-match（宽泛）/ substitutes（同类商品）/ complements（关联商品）。 全部留空时由亚马逊按广告组默认出价自动建 4 组。
自动目标竞价USD仅自动广告。
• 填 0.8 → 4 组统一 0.8
• 填 close-match:0.8;loose-match:0.6 → 分组定价（组名:价格，分号隔开）
• 组名：close-match 紧密 / loose-match 宽泛 / substitutes 同类 / complements 关联
• 留空 = 用广告组默认竞价；选「暂停」的组不填价也行
开始日期建议勾选「留空」，= 上传当天开始
加价是乘在关键词出价上的百分比：最终出价 ≈ 关键词出价 × (1 + 加价%)，再按竞价策略浮动（固定=不动；仅降低 0~-100%；提高和降低 ±100%）。

③ 投放词生成：适配表 + 大词 → 关键词

用途：一个 SKU 适配几十个车型时，按「年份/品牌/车型 + 大词」批量拼出搜索词广告关键词，并按保有量 VIO 从高到低排序。
步骤说明
1. 上传适配表列的识别：PDM商品编码/商品编码（=真正的卖家SKU）、产品编码/productCode（内部短码，仅做对照）、makeName/品牌、modelName/车型、yearName/年份、vio/保有量；没有结构化列时读 detail_us 文本（只读美国站，detail_canada/detail_mexico 一律忽略）。
SKU 只认 PDM商品编码；若适配表里只有产品编码，会自动去同一文件里找「产品编码 + PDM商品编码」的对照表补全，补不到会红字提示。 品牌/SKU 合并单元格（只在首行写）也能自动向下补齐。
2. 填大词如 blower motor / ac blower motor / hvac blower motor
3. 选词型 ☑ 年份+品牌+车型 → 2019 chevrolet silverado 1500 blower motor
☑ 品牌+车型 → chevrolet silverado 1500 blower motor
☑ 年份+车型 → 2019 silverado 1500 blower motor（默认不勾）
4. 可选参数匹配方式（默认 exact）、关键词竞价（留空=继承广告组默认出价）、每日预算（留空=20）、最多生成几个词（留空=全部）、广告组划分（每车型一组 / 全部合并）
5. 输出预览（按 VIO 降序）→ 下载关键词清单 xlsx/csv → 或点「➡ 填入批量创建广告清单」直接进页签①出上传文件
年份写成区间（如 2015-2020）会自动展开成逐年关键词，每个年份继承该行的 VIO； 同一个词只保留 VIO 最高的那条。填入清单时：一个 SKU 一个活动，广告组按车型划分，广告组默认出价=你填的竞价（没填则 0.75）。

生成的文件怎么用

1. 下载得到 .xlsx（或 .csv）
2. SC：卖家后台 → 广告 → 全部广告活动 → 批量操作 → 上传文件
3. VC：广告控制台 advertising.amazon.com → Sponsored ads → Bulk operations
4. 处理是异步的，结果和报错明细在批量操作页查看 / 下载 ErrorReport
5. 首次先小批量验证（1–2 个活动），通过后再放大
